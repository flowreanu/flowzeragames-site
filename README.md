# FlowZeraGames — website

Landing page for **FlowZeraGames**, interactive games for TikTok LIVE.

- **MIND RUSH**: the quiz game your viewers play from the chat. [Buy on Gumroad](https://flowzeragames.gumroad.com/l/mindrush)
- **THE EGG**: coming soon

Static site (one `index.html` and an `assets/` folder). There's no build step, so it deploys on Vercel as is.

The "Beat the chat" section is a small demo built for the site. The full game is **not** in this repository.
